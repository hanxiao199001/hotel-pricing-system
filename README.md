## 🚀 使用方法

### 手动运行

```bash
cd /root/hotel-pricing
python3 main.py
```

### 定时任务（每小时）

```bash
# 安装 crontab
crontab -e

# 添加：
0 * * * * cd /root/hotel-pricing && python3 main.py >> /var/log/hotel-pricing.log 2>&1
```

## ⚙️ 配置说明

编辑 `config.py` 修改参数：

敏感信息（携程账号、密码、酒店ID、通知手机号）不再写在代码里，统一通过环境变量配置。
复制 `.env.example` 为 `.env` 并填入真实值：

```bash
cp .env.example .env
# 编辑 .env 填入 CTRIP_USERNAME / CTRIP_PASSWORD / CTRIP_HOTEL_ID 等
```

定价策略仍在 `config.py` 中调整：

```python

# 定价策略
PRICING_STRATEGY = {
    "low_occupancy_threshold": 30,    # 低入住率阈值(%)
    "high_occupancy_threshold": 60,   # 高入住率阈值(%)
    "low_occupancy_discount": 10,     # 降价幅度(元)
    "high_occupancy_premium": 10,     # 涨价幅度(元)
    "min_price": 100,                 # 最低价保护
    "max_price": 180                  # 最高价限制
}
```
